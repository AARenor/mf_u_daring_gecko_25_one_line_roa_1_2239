# One-line gadget roast

This repository holds a small program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a single original line roasting a gadget or app used every day. The program is `main.py`, Python 3.13 with the standard library only and no network access; it asserts the text is between 1 and 280 characters, creates the output folder, writes `entry.txt` with no trailing newline, and prints the character count to stderr.
